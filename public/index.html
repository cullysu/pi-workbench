MCP

          

            
通过桥接扩展接入 MCP 服务器

            
pi 本体不做 MCP；这里维护标准的 mcpServers 配置（~/.pi/agent/mcp.json，与 Claude/Cursor 同格式），桥接扩展把其中每个工具注册成 pi 工具（mcp_服务器_工具）。连接是惰性的：第一次调用工具时才拉起对应服务器。

            

              
              
              
            

          

          
~/.pi/agent/mcp.json

          
          
保存后新开的会话生效（pi 启动时由扩展注册工具）。
