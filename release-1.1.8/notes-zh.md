# v1.1.8 — WS 心跳与限流冷却分级

外部技术评审（v1.1.7）可动项落地。

### Added
- **WS 心跳**：服务端每 30 秒 ping 一次，连续两拍无 pong 判定僵尸连接并拆除（浏览器与 ws 客户端在协议层自动应答 pong，活连接无感知）——死连接不再滞留占着 adopted 状态。
- **回退冷却分级**：`429 / rate limit / quota` 类错误冷却模型 **300 秒**（配额窗口通常是分钟级），其它失败维持 120 秒链步进；`401/403` 仍走按键轮换。

门禁：lint 0/0（含 npm audit）、35/35 测试、47/47 路由扫描、ws-probe（含 adopt 语义）/ failover-e2e 全 PASS；CI 8 job 全绿，五包同源单一 commit（23e0cd8）。

说明：内置 Node v22.14.0；仍未代码签名（需要证书账号，唯一遗留项）。
